# DermaVue paper workspace

This directory is a paper scaffold only. It intentionally contains no claimed
results, fabricated citations, or invented author/ethics information.

Planned manuscript files:

- `literature_review.md`
- `research_question_and_novelty.md`
- `methods.md`
- `dataset_and_ethics.md`
- `experiments.md`
- `results.md`
- `limitations.md`
- `manuscript.md`
- `references.bib`
- `reproducibility_checklist.md`

Draft results must be generated from versioned experiment outputs. Until genuine
data and evaluation exist, result sections should contain explicit placeholders
such as “pending genuine-data evaluation,” never numeric claims.
